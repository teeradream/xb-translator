## 🌟 ฟีเจอร์การทำงานทั้งหมด (Key Features)

1. **Xbox Remote Play & xCloud ในแอปเดียว:** เปิด `xbox.com/play` พร้อมโหลดสคริปต์ **Better xCloud** อัตโนมัติ รองรับการสตรีมจากเครื่อง **Xbox Series X|S / Xbox One** ที่บ้าน (Remote Play) และ **xCloud** สูงสุด 1080p
2. **ดีไซน์ Liquid Glass & Tactile Spring Physics:** หน้าต่างเมนูตั้งค่า (เด้งออกจากปุ่ม `☰`), ลิ้นชักปุ่มลัดด้านบน, หน้าต่างคำแปล และปุ่มกดทั้งหมดออกแบบสไตล์กระจกโปร่งแสงขอบสะท้อนแสง พร้อมเอฟเฟกต์ยุบ/เด้งสปริงเวลาแตะหรือลาก
3. **ระบบแยก 2 กรอบอิสระ (ซับไตเติล + แปลเฉพาะจุด):**
   - **กรอบซับไตเติล (สีเขียว):** อ่านและแปลซับต่อเนื่องอัตโนมัติ เรียงซ้อน 3 แถว ไล่ระดับความจาง (`1.0 → 0.65 → 0.35`)
   - **กรอบแปลเฉพาะจุด (สีฟ้า):** กดปุ่มวงกลมไอคอนกรอบข้างปุ่ม `☰` เพื่อแปลข้อความแนะนำ/ชีต/จดหมายแบบไม่ชนกับซับ แสดงเป็นหน้าต่างแยก มีปุ่ม **กากบาท (`✕`)**, ปุ่ม **"ฟังเสียงพากย์"** และปิดเองใน **20 วินาที** (ใช้งานได้แม้เปิด **โหมดจอดำเต็มจอ** โดยหน้าต่างจะแทรกด้านบนและดันซับลงด้านล่างชั่วคราว)
4. **ลิ้นชักปุ่มลัดด้านบน (Top Quick Drawer):** แตะหรือปัดแถบจับโปร่งแสงตรงกลางขอบบนเพื่อเปิด/ปิดด่วน 4 อย่าง: **พากย์**, **เสียงเกม**, **ซับ**, และ **จอดำ** (ซ่อนอัตโนมัติใน 4 วินาที)
5. **ปรับแต่งตัวหนังสือแบบสด (Live Subtitle Styling):** เลือกตำแหน่ง (กลาง/ล่างจอ), สี 6 สี, ขนาด (`16–42sp` + `A-`/`A+`), ความทึบพื้นหลัง (`0%–100%`), จำนวนแถว (`1–3`) พร้อมกล่องตัวอย่างสด
6. **รองรับ Gemini API Key (เลือกใช้ได้):** แปลภาษาเกมพร้อมคำแสลง/คำสบถได้ตรงอารมณ์ (`BLOCK_NONE`) และพากย์เสียง AI (สลับกลับระบบฟรีอัตโนมัติเมื่อไม่ใส่คีย์หรือโควตาเต็ม)
7. **พากย์เสียงไทย (TTS) + 3 โหมดคิวเสียง:**
   - **อ่านจบประโยค (ต่อคิว)** — เหมาะกับคัตซีน/เนื้อเรื่องที่พูดช้า
   - **ทันใจตามซับใหม่ (ตัดขึ้นทันที)** — ตัดประโยคเก่าทันทีเมื่อซับใหม่มา
   - **Smart Queue (ลูกผสม — แนะนำ)** — รอคิวได้ไม่เกิน 1 ประโยค ถ้าซับมาเร็วเกินจะตัดข้ามไปประโยคล่าสุดทันที
8. **จำค่าการตั้งค่าทั้งหมดถาวร:** จำทั้งสถานะเปิด/ปิดซับ, เสียงพากย์, รูปแบบตัวอักษร, กรอบสแกนทั้ง 2 กรอบ และ Gemini API Key

## 🎮 วิธีตั้งค่าเชื่อมต่อ Xbox Remote Play & xCloud

1. **เปิดใช้งานที่เครื่อง Xbox (เฉพาะ Remote Play):**
   - บนเครื่อง Xbox ไปที่ **Settings > Devices & connections > Remote features** แล้วติ๊กเปิด **Enable remote features**
2. **เปิดแอป XB Translator บนมือถือ/แท็บเล็ต:**
   - ล็อกอินบัญชี Microsoft ของคุณบนหน้า `xbox.com/play`
   - แตะไอคอน **Better xCloud** มุมขวาบนของหน้าเว็บ → เปิด **"Enable Remote Play feature"** แล้วรีโหลดหน้า
   - กดปุ่ม **Remote Play** (หรือเลือกเกม xCloud) เพื่อเริ่มเล่นได้ทันที!

## 🔍 วิธีใช้งานระบบแปลซับ & แปลเฉพาะจุด (2 กรอบอิสระ)

1. **ตั้งกรอบอ่านซับ (สีเขียว):**
   - แตะปุ่ม **`☰`** มุมขวาล่าง → **"โหมดหน้าจอ & กรอบตรวจจับซับ"** → **"ปรับกรอบพื้นที่ตรวจจับซับไตเติล"**
   - ลากครอบแถบซับไตเติลของเกมแล้วกด **บันทึกกรอบ**
2. **ตั้งกรอบแปลเฉพาะจุด (สีฟ้า — สำหรับเอกสาร/ชีต/ข้อความแนะนำ):**
   - ในเมนูเดียวกัน เลือก **"ปรับกรอบแปลเฉพาะจุด (เอกสาร/คำแนะนำ)"**
   - ลากครอบโซนที่เกมชอบขึ้นข้อความแนะนำหรือหน้ากระดาษแล้วกด **บันทึกกรอบ**
   - เวลาเล่นเกมแล้วเจอเอกสาร/ข้อความแนะนำ ให้กด **ปุ่มวงกลมไอคอนกรอบ** ข้างๆ ปุ่ม `☰` ได้ทันที (ใช้งานได้ทั้งหน้าจอเกมปกติและจอดำเต็มจอ)

## 🧲 การใช้งานลิ้นชักปุ่มลัดด้านบน (Top Quick Drawer)

- แตะหรือปัดลงที่ **แถบจับโปร่งแสงตรงกลางขอบบนสุดของหน้าจอ**
- ลิ้นชักจะเด้งลงมาให้กดสลับได้ทันที 4 ปุ่ม: **พากย์**, **เสียงเกม**, **ซับ**, และ **จอดำ**
- หากไม่ได้กดต่อภายใน **4 วินาที** ลิ้นชักจะเลื่อนซ่อนกลับขึ้นไปเองโดยไม่บังจอ

## 🤖 การตั้งค่า Gemini API (แปลคำแสลง/สบถ & พากย์ AI)

1. ขอ API Key ฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/apikey) (จะได้คีย์ขึ้นต้นด้วย `AIzaSy...`)
2. ในแอป แตะ **`☰`** → **"ตั้งค่า Gemini API (แปล & พากย์ AI)"**
3. วางคีย์ลงในช่องแล้วกด **"บันทึก API Key"**
   - **ทิปประหยัดโควตาฟรีและไม่มีดีเลย์เสียง:** แนะนำให้ **เปิด** `"ใช้ Gemini แปลภาษา"` เพื่อให้แปลคำแสลง/บทพูดได้ธรรมชาติ และ **ปิด** `"ใช้ Gemini AI พากย์เสียง"` เพื่อใช้เสียง TTS ในเครื่องคู่กับ **Smart Queue** จะพากย์ทันจังหวะเกมและไม่สลับเสียงไปมาครับ

## 🎧 การใช้งานร่วมกับหูฟัง Bluetooth และ Samsung DeX

- **Bluetooth:** เสียงพากย์ไทยส่งออกหูฟัง/ลำโพง Bluetooth ให้อัตโนมัติ (สามารถกดปิดเสียงเกมจากมือถือในลิ้นชักด้านบนเพื่อฟังเฉพาะเสียงพากย์ไทยได้)
- **Samsung DeX:** ต่อสาย HDMI/Type-C ขึ้นจอมอนิเตอร์หรือทีวีได้เต็มหน้าจอ พร้อมรองรับจอย Xbox / DualSense / Bluetooth มาตรฐาน
